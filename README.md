# متجر إلكتروني متكامل باستخدام Django

متجر إلكتروني (E-commerce) كامل ومترابط مبني بإطار عمل Django للباك إند، مع HTML5، CSS3، و JavaScript للفرونت إند.

## المميزات

- **عرض المنتجات**: تصفح المنتجات مع الفلترة حسب الفئة والبحث والترتيب
- **تفاصيل المنتج**: صفحة تفصيلية لكل منتج مع منتجات مشابهة
- **سلة التسوق**: إضافة، تحديث، وإزالة المنتجات (تعمل عبر الجلسة)
- **نظام المستخدمين**: تسجيل، دخول، خروج، وملف شخصي
- **إتمام الشراء**: عملية شراء كاملة مع معلومات التوصيل
- **إدارة الطلبات**: عرض الطلبات وتفاصيلها مع تتبع الحالة
- **لوحة الإدارة**: إدارة المنتجات، الفئات، الطلبات، والمستخدمين
- **واجهة عربية**: دعم كامل للغة العربية مع RTL
- **تصميم متجاوب**: يعمل على جميع الأجهزة

## هيكل المشروع

```
├── config/              # إعدادات Django
├── store/               # تطبيق المنتجات والفئات
├── accounts/            # تطبيق المستخدمين والملف الشخصي
├── cart/                # تطبيق سلة التسوق
├── orders/              # تطبيق الطلبات
├── templates/           # قوالب HTML
├── static/              # CSS و JavaScript
├── media/               # صور المنتجات
└── manage.py
```

## التثبيت والتشغيل

### 1. تثبيت المتطلبات

```bash
pip install -r requirements.txt
```

### 2. تطبيق التغييرات على قاعدة البيانات

```bash
python manage.py migrate
```

### 3. إنشاء بيانات تجريبية

```bash
python manage.py seed_data
```

### 4. إنشاء حساب مدير (اختياري)

```bash
python manage.py createsuperuser
```

### 5. تشغيل الخادم

```bash
python manage.py runserver
```

افتح المتصفح على: **http://127.0.0.1:8000/**

لوحة الإدارة: **http://127.0.0.1:8000/admin/**

## الصفحات

| الصفحة | الرابط |
|--------|--------|
| الرئيسية | `/` |
| المنتجات | `/products/` |
| تفاصيل منتج | `/products/<slug>/` |
| الفئة | `/categories/<slug>/` |
| سلة التسوق | `/cart/` |
| تسجيل دخول | `/accounts/login/` |
| إنشاء حساب | `/accounts/register/` |
| حسابي | `/accounts/profile/` |
| إتمام الشراء | `/orders/checkout/` |
| طلباتي | `/orders/my-orders/` |

## التقنيات المستخدمة

- **Backend**: Django 4.2
- **Frontend**: HTML5, CSS3, JavaScript
- **Database**: SQLite (قابل للتغيير)
- **Forms**: django-crispy-forms + Bootstrap 5
- **Images**: Pillow

## المتطلبات

- Python 3.10+
- pip
